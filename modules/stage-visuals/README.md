# Stage Visuals Live

Beat-synced stage visuals you control live from a laptop, phone, or your keyboard.

**Start:** open `index.html` in Chrome or Edge. For the keyboard (MIDI), it works best served locally:
run `python3 -m http.server` in this folder and open http://localhost:8000.

See `CLAUDE.md` for the full feature list, how it works, and what to test next.
